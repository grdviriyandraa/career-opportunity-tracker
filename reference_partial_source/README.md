# Source Referensi Parsial

Source ini berasal dari /workspace/sites/gerard-opportunity-hub pada audit 4 November 2026. Ini bukan checkout GitHub dan bukan aplikasi selesai. Halaman utama placeholder. TypeScript dan build Vinext pada lingkungan asal lulus; pengujian alur pengguna, database produksi dan live Google belum dilakukan.

Folder ini hanya menyertakan file yang relevan untuk memahami model, form, API, database dan adapter lama. Data pribadi data/migration.json, dependencies, build output, kredensial, konfigurasi deployment dan template UI yang tidak relevan tidak disertakan. Import terhadap file yang tidak disertakan dibiarkan utuh sebagai bukti source; paket ini tidak dapat dijalankan mandiri.

Jangan menggunakan autentikasi berbasis header gateway ChatGPT pada hosting internet biasa. Jangan menyalin environment Cloudflare/D1 ke Next.js Node tanpa adapter baru. Ikuti GAP01–GAP22 di IMPLEMENTATION_HANDOFF.md. PRD v3 dan kontrak integrasi terbaru mengungguli perilaku kode ini.

MANIFEST.json menyimpan original relative path, byte size dan SHA-256 setiap file yang disalin. Hash dapat digunakan untuk memastikan snapshot tidak berubah. Tidak ada token atau data tracker yang sengaja disertakan dalam snapshot ini.
