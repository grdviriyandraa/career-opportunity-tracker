# Contoh kontrak

Semua record contoh sintetis, bukan data pengguna atau employer nyata. Payload penelitian sengaja tidak berisi personal stage atau applied dates. Server menghitung canonical content hash dan ledger key; API preview harus menambahkan preview ID, hash dan expiry sendiri. Contoh emergency patch adalah input preview, bukan izin langsung untuk apply. Env template hanya nama konfigurasi yang diusulkan dan belum dibaca oleh source referensi lama.

## Tambahan versi 3

hermes.config.example.yaml memakai path placeholder dan adapter yang belum dibuat. create_draft.schema.json memvalidasi bentuk input; backend tetap memvalidasi URL/SSRF, byte limits dan otorisasi. Agent response dan request adalah fixture sintetis. HERMES_BEHAVIOR.md adalah policy prompt, bukan skill terpasang dan bukan pengganti security boundary. Token-file dibaca bridge dari path privat; jangan menambahkan file secret ke paket.

## Contoh versi 3.1

research_history.synthetic.json menyediakan dua run buatan, baseline dua record lama dan satu koreksi tertahan. HERMES_QA_CASES.md memuat 20 dialog beserta hasil yang diharapkan untuk WP08.
