## Bukti dan penggunaan

Baca log dengan mencocokkan nilai Run ID. Di tengah tab terdapat baris judul dan rincian batch pencarian yang bukan record run. Cocokkan Record ID dan Last Research Run ID saat memeriksa tabel peluang. Gunakan log historis untuk angka pada tanggal tertentu; tabel peluang memuat keadaan terakhir dan dapat berubah sesudah run lain. Jika log dan detail berbeda, dokumentasikan selisih dan tahan rekonsiliasi. Hindari menulis ulang histori dengan keadaan terkini.
